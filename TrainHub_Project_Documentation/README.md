# TrainHub — Project Documentation

TrainHub adalah MVP portal pelatihan karyawan berbasis web dengan fokus pada interaksi dua arah, distribusi materi/tugas, dan evaluasi capaian.

## Pendekatan
Project menggunakan **Object-Oriented Analysis (OOA)** dan desain berlapis agar sistem mudah dipahami, diimplementasikan, dan diuji.
